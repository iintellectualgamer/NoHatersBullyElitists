1. COMPLETE SLASH COMMAND (/) REFERENCE DIRECTORY
--------------------------------------------------------------------------------
NoHatersBullyElitists_Classic registers three primary base slash commands (/nhbe,
/nhbeclassic, and /nohaters) along with sub-command arguments so you can control
the security suite from chat or inside macros at any time.

* /nhbe
  - Action / Target : Toggle Main Window
  - Detailed Effect : Opens or closes the main 6-Tab Enterprise Security & Blizzard
                      Ticket Suite frame and refreshes all live counters.

* /nhbeclassic
  - Action / Target : Toggle Main Window (Classic Alias)
  - Detailed Effect : Dedicated Classic manifest command. Identical to /nhbe;
                      toggles the main 6-Tab window on or off.

* /nohaters
  - Action / Target : Toggle Main Window (Full Alias)
  - Detailed Effect : Full-word command alias. Opens or hides the main 6-Tab window
                      and recalculates all 9 filter counters.

* /nhbe test  |  /nhbeclassic test  |  /nohaters test
  - Action / Target : Simulate Test Alert
  - Detailed Effect : Opens the main window and triggers Simulate Test Alert,
                      injecting 3 sample rule violations (Scam/Phishing link,
                      Whisper Harassment, and Gold/GDKP Theft) plus 1 unflagged
                      Protected Core Belief message.

* /nhbe clear  |  /nhbeclassic clear  |  /nohaters clear
  - Action / Target : Clear Logs & Optimize RAM
  - Detailed Effect : Purges all session and saved chat logs in the database,
                      resets repeat-offender counters to zero, and prints a
                      confirmation in chat.

ADDITIONAL MOUSE & UI QUICK-ACCESS CONTROLS:
* Floating Shield / Minimap Button: Left-click the Shield icon to toggle the main
  window open or closed. Left-click and drag to reposition it.
* Minimap Addon Compartment Tray: On modern clients supporting the Addon Compartment
  dropdown, click NoHatersBullyElitists in the top-right minimap tray to toggle the suite.

2. INSTALLATION & FILE STRUCTURE GUIDE
--------------------------------------------------------------------------------
The addon is engineered with a self-healing compatibility layer supporting World of
Warcraft Classic Era, Season of Discovery, Burning Crusade, Wrath of the Lich King,
Cataclysm, Mists of Pandaria Classic, and Forever Retail.

1. Locate your World of Warcraft installation directory and open the Interface\AddOns\
   folder for your active client (_classic_era_, _classic_, _retail_).
2. Ensure the folder is named NoHatersBullyElitists.
3. Place the .toc and .lua files inside that folder.
4. Launch World of Warcraft or type /reload in chat. Verify the startup confirmation message.

3. CORE POLICY: LEGITIMATE HARASSMENT VS. PROTECTED CORE BELIEFS
--------------------------------------------------------------------------------
A core requirement of NoHatersBullyElitists_Classic is ensuring that every recorded
incident and exported Blizzard Game Master (GM) ticket represents legitimate,
actionable harassment rather than a disagreement over someone's personal opinion
or core belief.

LEGAL & POLICY CLASSIFICATION STATEMENT (EMBEDDED IN ALL TICKET EXPORTS):
This dossier strictly filters and records actionable, continuous harassment, targeted
verbal abuse, threats, malicious stalking, and financial/item scams in direct violation
of the Blizzard Entertainment In-Game Code of Conduct.

NON-INFRINGEMENT OF OPINION & CORE PERSONAL/PROFESSIONAL BELIEFS:
This report explicitly EXCLUDES and does NOT target players for expressing harmless
personal opinions, gameplay preferences, constructive tactical feedback, or core
personal, philosophical, religious, or professional beliefs. An entry is flagged as
[LEGITIMATE HARASSMENT] only when behavior crosses the threshold into targeted malice,
repeated unwanted contact (e.g., bypassing /ignore via alts, continuous whisper
beratement), severe toxicity, derogatory slurs, or fraudulent theft/phishing.

COMPARISON OF FLAGGED VIOLATIONS VS. PROTECTED EXPRESSION:
* Actionable Violations (Flagged & Logged for GM Action):
  - Continuous Harassment & Bullying: Direct insults ("worthless", "trash player",
    "uninstall"), self-harm threats ("kys", "kill yourself"), malicious wishes,
    social sabotage ("blacklist you", "kick this"), and rolling alternate characters
    to bypass /ignore.
  - Scams, Phishing & Gold/Item Theft: External phishing/RMT links (http, www.,
    discord.gg, .com), fake GM impersonation whispers, ninja looting, unreturned
    gold loans, crafting material scams, and GDKP pot fraud.

* Protected Expression (Excluded from Violation Flagging):
  - Core Personal & Professional Beliefs: Statements prefaced with or expressing
    core personal, philosophical, religious, or professional beliefs (e.g., "In my
    personal opinion and core professional belief, playing with respect makes every
    raid smoother").
  - Constructive Gameplay & Tactical Opinions: Neutral or respectful gameplay
    preferences, talent discussions, and boss routing suggestions (e.g., "I think we
    should lust on pull", "Tactically speaking, frost is safer here") that contain
    zero slurs or threats.

4. TAB-BY-TAB WALKTHROUGH OF THE 6-TAB ENTERPRISE SUITE
--------------------------------------------------------------------------------
TAB 1: 1. Live Feed (Live Threat & Chat Monitor)
Displays real-time chat traffic and rule violations with live numerical counters in
parentheses on every category button:
  - All (0)        [ALL]     : Displays every logged message across all monitored channels.
  - Whispers (0)   [WHISPER] : Isolates incoming Whispers and Battle.net Whispers.
  - Guild (0)      [GUILD]   : Isolates Guild chat and Officer chat.
  - Party/Raid (0) [PARTY]   : Isolates Party, Raid, Raid Warning, and Instance chat.
  - Say/Yell (0)   [SAY]     : Isolates local Say, Yell, and Emote channels.
  - Trade/Pub (0)  [PUBLIC]  : Isolates public numbered channels (Trade, Services, General, LFG).
  - Flagged (0)    [FLAGGED] : Shows ONLY verified rule violations (Harassment, Scams, Theft).
  - Scams (0)      [SCAM]    : Shows ONLY external link alerts and fake GM phishing attempts.
  - Theft/Gold (0) [THEFT]   : Shows ONLY Item & Gold Theft alerts (ninja loot, loans, GDKP).

TAB 2: 2. Ticket Export (1-Click Blizzard Support Ticket Dossier Generator)
  1. Ongoing Harassment (Best): Exports all flagged harassment, toxicity, and abusive chat.
  2. Item / Gold Theft Scam: Exports all logs flagged under THEFT/GOLD.
  3. Phishing / Fake GM Link: Exports all logs flagged under SCAM/PHISH.
  4. Full Session Transcript: Exports the complete chronological session log.

TAB 3: 3. Blizzard Report (Policy & Verification Standards)
Provides an in-game reference manual detailing why distinguishing legitimate harassment
from personal/professional beliefs matters to Blizzard Game Masters.

TAB 4: 4. Blacklist & Rules (Continuous Offender Manager)
Allows you to permanently record known stalkers, bullies, and gold thieves.

TAB 5: 5. Performance & RAM (Zero-Lag O(1) Engine Diagnostics)
Displays real-time technical telemetry for the addon's self-healing engine.

TAB 6: 6. Visual Manual (Quick-Jump Visual Encyclopedia & Author Credits)
Contains the in-game Quick-Jump Visual Encyclopedia and copyable author links.

5. BOTTOM ACTION BAR REFERENCE (PERSISTENT ACROSS ALL TABS)
--------------------------------------------------------------------------------
* Clear Session Logs     : Wipes all currently stored chat logs (/nhbe clear).
* Sound Alerts: ON / OFF : Toggles the in-game Raid Warning audio alert (SoundKitID 8959).
* Chat Warnings: ON / OFF: Toggles real-time red/orange warning banners in chat.
* Simulate Test Alert    : Generates 4 realistic test events (/nhbe test).
* Jump to Ticket Export  : Switches directly to Tab 2 (Ticket Export).
