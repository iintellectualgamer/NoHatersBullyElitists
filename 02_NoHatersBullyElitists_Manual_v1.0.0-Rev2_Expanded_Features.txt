1. EXPANDED SLASH COMMAND DIRECTORY (REVISION 2)
--------------------------------------------------------------------------------
Type any of these commands in your World of Warcraft chat box or inside a macro:

* /nhbe or /nhbeclassic or /nohaters
  Toggles the main 6-Tab Enterprise Security & Blizzard Ticket Suite window open or closed.
* /nhbe mini (or /nohaters mini)
  Collapses the main window into the compact, draggable Floating Minimize Bar, or
  expands it back to full size.
* /nhbe urls (or /nohaters urls)
  Opens Tab 3 directly to access all 8 Official Blizzard Complaint & Support URL buttons
  (1 button per official support page) with the 1-Click Ctrl+C URL Copy Box.
* /nhbe scope (or /nohaters scope)
  Switches chat storage between Account-Wide Shared Logs (NoHatersBullyElitistsDB)
  and Per-Character Isolated Logs (NoHatersBullyElitistsCharDB).
* /nhbe soundtest (or /nohaters soundtest)
  Plays an immediate Master-channel audio test chime so you can verify your sound levels.
* /nhbe test (or /nhbeclassic test or /nohaters test)
  Opens the main window and triggers Simulate Test Alert.
* /nhbe clear (or /nhbeclassic clear or /nohaters clear)
  Wipes all session and saved chat logs for your currently active storage scope.

2. MINIMIZE BAR & UPPER-RIGHT MINIMAP BUTTON CONTROLS
--------------------------------------------------------------------------------
A. FLOATING MINIMIZE BAR (NHBE_MinimizeBar):
   - Click the [Minimize [_]] button in the top-right corner of the main window (next to [X])
     or type /nhbe mini.
   - Collapses the suite into a sleek 470x34 floating bar displaying live counters:
     "NHBE | All: X | Flagged: Y | Acct/Char"
   - Includes 1-click buttons right on the bar: [Tickets], [Blizz URLs], and [Expand [+]].

B. UPPER-RIGHT MINIMAP ICON (NHBE_MinimapButton):
   - Anchored by default at 45 degrees (Upper-Right rim of the Minimap).
   - Left-Click       : Toggle the Main Security Suite Window open or closed.
   - Shift+Left-Click : Toggle the Floating Minimize Bar on or off.
   - Right-Click      : Open Tab 3 (8 Official Blizzard Complaint & Support URLs).
   - Left-Drag        : Smoothly reposition the icon anywhere along the Minimap rim.

3. ACCOUNT-WIDE VS. PER-CHARACTER CHAT SEPARATION (TAB 4 & BOTTOM BAR)
--------------------------------------------------------------------------------
* Account-Wide Mode (Default — Scope: Account):
  Uses SavedVariables (NoHatersBullyElitistsDB) so all characters across your World of
  Warcraft account share a unified violation log and blacklist.
* Per-Character Mode (Scope: Character):
  Uses SavedVariablesPerCharacter (NoHatersBullyElitistsCharDB) so Tab 1 Live Feed and
  Tab 2 Ticket Dossiers only display chat messages recorded on the active character.
* Non-Destructive Switching:
  Incoming messages are safely written to both databases simultaneously.
