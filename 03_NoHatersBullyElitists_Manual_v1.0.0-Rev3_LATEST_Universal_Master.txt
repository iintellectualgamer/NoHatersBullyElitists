1. COMPLETE SLASH COMMAND DIRECTORY
--------------------------------------------------------------------------------
Type any of these commands in your World of Warcraft chat box or inside a macro:

* /nhbe or /nhbeclassic or /nohaters
  Toggles the main 6-Tab Enterprise Security & Blizzard Ticket Suite window open or closed.

* /nhbe restore (or /nohaters restore or /nhbe reset)
  Immediately restores all default text across Tabs 1, 2, 4, and 6 back the way it was
  (you can also type /reload in chat at any time to restore all original text).

* /nhbe mini (or /nohaters mini)
  Collapses the main window into the compact, draggable Floating Minimize Bar, or
  expands it back to full size.

* /nhbe urls (or /nohaters urls)
  Opens Tab 3 directly to access all 8 Official Blizzard Complaint & Support URL buttons
  (1 button per official support page) with the 1-Click Ctrl+C URL Copy Box.

* /nhbe scope (or /nohaters scope)
  Switches chat storage between Account-Wide Shared Logs (NoHatersBullyElitistsDB)
  and Per-Character Isolated Logs (NoHatersBullyElitistsCharDB).

* /nhbe soundtest (or /nohaters soundtest)
  Plays an immediate Master-channel audio test chime so you can verify your sound levels.

* /nhbe test (or /nhbeclassic test or /nohaters test)
  Opens the main window and triggers Simulate Test Alert, generating realistic test
  incidents (Trade Services Discord scam link, Party/Whisper harassment, Party GDKP/loan
  theft, and a Protected Core Belief message) to test filtering and Ticket Dossier export.

* /nhbe clear (or /nhbeclassic clear or /nohaters clear)
  Wipes all session and saved chat logs for your currently active storage scope and
  resets repeat-offender counters to zero.

4. ACCOUNT-WIDE VS. PER-CHARACTER CHAT SEPARATION (TAB 4 & BOTTOM BAR)
--------------------------------------------------------------------------------
* Account-Wide Mode (Default — Scope: Account):
  Shares captured chat logs and repeat-offender counts across all characters on your
  World of Warcraft account via NoHatersBullyElitistsDB.
* Per-Character Mode (Scope: Character):
  Isolates Tab 1 Live Feed and Tab 2 Ticket Dossiers strictly to your active character
  via NoHatersBullyElitistsCharDB.
* Non-Destructive Switching:
  Messages are recorded to both databases simultaneously so switching scopes never loses logs.
