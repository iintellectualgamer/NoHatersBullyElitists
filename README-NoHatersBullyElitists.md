# NoHatersBullyElitists v1.0.0

Initial public release. The install ZIP includes three revisions of the text manual.

NoHatersBullyElitists brings a searchable chat log, keyword alerts, and copyable Blizzard support drafts into one six-tab window. Open the bundled **Rev 3 Universal Master manual** for the full walkthrough. The manual is named `03_NoHatersBullyElitists_Manual_v1.0.0-Rev3_LATEST_Universal_Master.txt`.

## Install

1. Close World of Warcraft. Download and extract `NoHatersBullyElitists-v1.0.0.zip`. [GitHub v1.0.0 release](https://github.com/iintellectualgamer/NoHatersBullyElitists/releases/tag/v1.0.0)
2. Copy the **NoHatersBullyElitists** folder into the `Interface\AddOns` folder for your edition.

   - Retail uses `_retail_\Interface\AddOns`.
   - Forever uses `_forever_\Interface\AddOns`.
   - Expansion Classic and Classic Era typically use `_classic_` and `_classic_era_`.
     Use your launcher's game folder for your edition.

3. Check for `Interface\AddOns\NoHatersBullyElitists\NoHatersBullyElitists.toc`. Enable **NoHatersBullyElitists** on the character screen.
4. Log in and check for **NoHatersBullyElitists v1.0.0** in the startup chat message. Use `/nhbe` or left-click the minimap shield to toggle the window. Shift + left-click or middle-click toggles the floating bar. Right-click opens **Blizzard URLs**. Drag the shield to move it.

For an update, copy the new addon files over the existing **NoHatersBullyElitists** folder with WoW closed. The addon stores its settings and captured chat locally in WoW's `WTF` SavedVariables.

## Review chat and prepare a report

- **Live Feed** captures incoming character whispers, guild and officer chat, party, raid, instance, say, yell, and public channels. Filter by channel or keyword flag, or search by sender or message text. Each history retains up to 1,000 messages.
- **Ticket Export** turns captured chat into a copyable draft with the time, sender, channel, zone, and message. **Ongoing Harassment** includes all flagged entries. **Item/Gold Theft Scam** and **Phishing/Fake GM Link** select their matching categories. **Full Session Transcript** includes the retained history in the current scope. Review the context and copy the text with Ctrl+C.
- **Blizzard URLs** offers eight copyable support and policy shortcuts, including US and EU support and player-reporting information. Use Blizzard's reporting controls to submit a report.
- **Blacklist & Scope** switches between the account-wide and current-character histories for Live Feed and Ticket Export. The local blacklist lists senders after three keyword matches in the active scope. Read matching messages in context before deciding what to report.
- **Audio & Test** plays sample sounds for phishing, theft, and harassment flags. The main window has separate **Sound Alerts** and **Chat Warnings** controls. **Simulate Test Alert** adds sample messages to the local log. This tab also has minimap shield position and visibility controls.
- **Visual Manual** contains the in-game guide. Use **Restore Default Text** or `/nhbe restore` to restore the display text. **Clear Session Logs** clears chat history and flag counters for the selected scope.

## Quick commands

- `/nhbe`, `/nhbeclassic`, or `/nohaters` toggles the main window.
- `/nhbe mini` toggles the floating bar with chat counters and shortcuts.
- `/nhbe urls` opens **Blizzard URLs**.
- `/nhbe scope` switches the history between account-wide and current-character views.
- `/nhbe restore` restores the default display text.
- `/nhbe soundtest` plays a sample alert.
- `/nhbe test` runs the simulated alerts.
- `/nhbe clear` clears the selected scope's chat log and flag counters.
