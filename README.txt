Install

1. Close World of Warcraft and extract NoHatersBullyElitists-v1.0.1.zip (or NoHatersBullyElitists-v1.0.0.zip if installing the archived v1.0.0 release).
2. Copy the NoHatersBullyElitists folder into the Interface\AddOns folder for your edition.

   - Retail uses _retail_\Interface\AddOns.
   - WoW Forever uses _forever_\Interface\AddOns.
   - Expansion Classic and Classic Era typically use _classic_\Interface\AddOns and _classic_era_\Interface\AddOns. Use your launcher's game folder for your edition.

3. Check for Interface\AddOns\NoHatersBullyElitists\NoHatersBullyElitists.toc and confirm it shows ## Version: 1.0.1 (or ## Version: 1.0.0 for the archived v1.0.0 release). Open AddOns on the character selection screen and enable NoHatersBullyElitists.
4. Log in and type /nhbe to open the six-tab window. Use Minimize [_] or /nhbe mini to collapse the window and Expand [+] to restore it. Left-click the minimap shield to toggle the window, right-click it to open Blizzard Report, or drag it around the minimap rim. Use /nhbe test to generate sample alerts.

For an update from an older build (such as upgrading from v1.0.0 to v1.0.1), close World of Warcraft and copy the new addon files over the existing NoHatersBullyElitists folder. Account-wide and per-character saved data lives in WTF.

Ethical & Protected Belief Standard (Why This Addon Exists)

Game Masters evaluate tickets based on objective violations of the Blizzard Entertainment In-Game Code of Conduct. Reporting players merely for disagreeing on talent builds, dungeon routing, or expressing personal beliefs dilutes report queues.

NoHatersBullyElitists uses an ethical classification engine that separates actionable violations from protected expression:

* What IS Flagged (Actionable Violations):
  * Continuous Harassment & Bullying: Repeated unwanted contact, bypassing /ignore via alternate characters (alt whisper), targeted personal abuse (loser, worthless, trash player, uninstall), and severe threats.
  * Phishing & Fake GM Links: External phishing URLs (http, www.), fake Blizzard GM impersonation whispers, and account-suspension scam links.
  * Item, Loot & Loan Theft Reports: Ninja looting, stolen raid/dungeon items, crafting material theft, GDKP pot fraud, and defaulted gold loan scams. (Note: Routine Trade/Services boosting advertisements are ignored so your Theft tab stays 100% focused on real theft reports.)
* What is EXCLUDED & Protected (Never Flagged):
  * Harmless personal opinions, constructive tactical raid/dungeon feedback, and core personal, ethical, moral, philosophical, religious, or professional beliefs shared without targeted malice.

Key Features Across All 6 Tabs

Tab 1: Live Threat & Chat Monitor (1. Live Feed)

* Live Numerical Filter Buttons (9 in v1.0.0; expanded to 11 in v1.0.1): Every button displays its real-time message count in parentheses and highlights in emerald-green brackets (> Name (Count) <) when active:
  * All (X) — Displays 100% of captured messages from all monitored channels.
  * Whispers (X) — Isolates private incoming/outgoing Whispers and Battle.net Whispers.
  * Guild (X) — Isolates Guild and Officer chat.
  * Party/Raid (X) — Isolates Party, Raid, Instance, and Battleground chat.
  * Say/Yell (X) — Isolates local Say, Yell, and Emote channels.
  * Trade/Pub (X) — Isolates Public channels (Trade, General, LocalDefense).
  * Flagged (X) — Isolates all rule violations (Harassment + Scams + Theft + Blacklist).
  * Scams (X) — Isolates phishing links and fake Blizzard GM whispers.
  * Theft (X) — Isolates item/loot theft, ninja looting, crafting material scams, and loan fraud for GM recovery reports.
  * Escalated (X) (Added in v1.0.1) — Isolates repeat offenders tagged with [ESCALATED x3+] at 3 or more flagged violations.
  * Pinned (X) (Added in v1.0.1) — Isolates critical evidence bookmarked with [PINNED] tags.
* Instant Search & Readout Bar: Filter by player name or keyword in real time (Filter: [X] | Query: [X] | Showing: X (Total Logged: Y)).

Slash Commands

* /nhbe (or /nhbeclassic or /nohaters) — Toggles the main 6-Tab Security Suite window open or closed.
* /nhbe test — Opens the main window and fires the Simulate Test Alert generator.
* /nhbe clear — Clears all session and saved chat logs and optimizes memory.
* Minimap & Floating Shield Button: Click the draggable Shield Icon or the WoW Minimap Addon Compartment entry (NoHatersBullyElitists) to toggle the window at any time.

Command | What it does
/nhbe, /nhbeclassic, /nohaters | Toggles the main six-tab window.
/nhbe test, /nhbeclassic test, /nohaters test | Opens the window and generates sample alerts.
/nhbe restore, /nhbeclassic restore, /nohaters restore | Opens the window, resets the Live Feed filter and search, regenerates the ticket dossier, and restores the built-in manual text.
/nhbe reset, /nhbeclassic reset, /nohaters reset | Runs the same command as /nhbe restore.
/nhbe resettext, /nhbeclassic resettext, /nohaters resettext | Runs the same command as /nhbe restore.
/nhbe mini, /nhbeclassic mini, /nohaters mini | Switches between the main window and the floating minimize bar.
/nhbe urls, /nhbeclassic urls, /nohaters urls | Opens Tab 3, Blizzard Report, with the official support links.
/nhbe scope, /nhbeclassic scope, /nohaters scope | Switches between account-wide and per-character chat logs.
/nhbe soundtest, /nhbeclassic soundtest, /nohaters soundtest | Plays a sample alert on the Master sound channel.
/nhbe clear, /nhbeclassic clear, /nohaters clear | Clears chat logs and offense counts for the active storage scope.
/nhbe escalated (v1.0.1) | Filters the Live Feed to repeat offenders with 3+ flagged violations ([ESCALATED x3+]).
/nhbe trust <name> (v1.0.1) | Adds a player to the Trusted Player Whitelist to prevent false-positive flags.
/nhbe untrust <name> (v1.0.1) | Removes a player from the Trusted Player Whitelist.
/nhbe review (v1.0.1) | Opens Latest Flag / Player Draft review in Tab 2's Ticket Dossier.
/nhbe pin (v1.0.1) | Pins the latest flagged message as [PINNED] critical evidence.
/nhbe unpin (v1.0.1) | Removes a [PINNED] critical evidence bookmark.
/nhbe allow <phrase> (v1.0.1) | Adds a custom safe phrase to the Tab 5 Protected Belief & Safe-Phrase Allowlist.
/nhbe unallow <phrase> (v1.0.1) | Removes a custom safe phrase from the Tab 5 Safe-Phrase Allowlist.
/nhbe check <message> (v1.0.1) | Runs a non-saving Live Match Preview test on a sample message.
/nhbe stats (v1.0.1) | Displays Live Session Threat Statistics (logged messages, Harassment, Scam, Theft, Escalated, Pinned, and Trusted counts).
